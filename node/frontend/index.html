Lumen will POST payment.received events to your URL, signed with HMAC-SHA256.

3-step quickstart

1 — Create invoice

curl -X POST /api/v1/invoices \
-H "Authorization: Bearer lm_live_YOUR_KEY" \
-H "Content-Type: application/json" \
-d '{"amount_sats": 5000, "description": "Order #42"}'

2 — Show QR to customer

const { bolt11, id } = await res.json();
// display bolt11 as QR code in your checkout

3 — Receive webhook on payment

POST https://yourdomain.com/lumen-webhook
X-Lumen-Signature: sha256=abc123...

{
"event": "payment.received",
"data": { "invoice_id": "...", "amount_sats": 5000 }
}
